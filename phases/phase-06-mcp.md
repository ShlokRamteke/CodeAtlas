# Phase 6 — MCP

## Goal

Expose Project Archaeologist's current-system and historical intelligence to
coding agents.

## Prerequisites

Phase 4 complete.

## Tasks

- MCP server
- read-only archaeology tools
- architecture lookup
- history lookup
- pre-change context
- authorization
- compact responses

## Definition of Done

A coding agent can ask for:
- current architecture,
- relevant dependencies,
- historical context,
- why a component exists,
- what to know before changing it.

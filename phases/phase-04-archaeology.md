# Phase 4 — Archaeological Investigation

## Goal

Connect current-system understanding with history and engineering context to
answer:

> **Why is the system like this?**

## Prerequisites

Phase 3 complete.

## Tasks

- Why Does This Exist?
- investigation planner
- read-only investigation tools
- evidence correlation
- reasoning
- evidence verification
- confidence/uncertainty

## Signature Workflow

```text
Current Component
      ↓
Current Dependencies
      ↓
Historical Changes
      ↓
PRs / Issues / Docs
      ↓
Evidence Correlation
      ↓
AI Explanation
```

## Definition of Done

A developer can ask why a component or behavior exists and receive a grounded
answer with evidence and confidence.

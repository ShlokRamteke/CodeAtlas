# Phase 3 — Historical + Engineering Context

## Goal

Build the historical and surrounding engineering evidence that explains the
current system.

Core question:

> **How did this software become what it is?**

## Prerequisites

Phase 2 complete.

## Tasks

- commits
- file history
- introducing changes
- pull requests
- issues
- documentation
- embeddings
- hybrid retrieval
- evidence relationships

## Key Output

A project intelligence layer combining:
- current state,
- history,
- engineering context.

## Definition of Done

Representative questions can retrieve relevant current and historical evidence.
